# Karishma & Salman — The Royal Wedding Invitation

A digital wedding invitation web application celebrating the holy matrimony of **Karishma Siddiqui & Salman Siddiqui**.

## ✦ Features

- **Interactive Royal Envelope Reveal**: Synchronized GSAP opening animation unveiling the wax seal and unfolding invitation directly into the Islamic Bismillah and family blessings.
- **Interactive "Save the Date" Scratch Card**: Gold foil scratch card with touch/drag scratch physics, auto-reveal threshold, and direct reveal action.
- **Dynamic Countdown Timer**: Live countdown to the auspicious Nikah ceremony (05 December 2026).
- **Wedding Events Timeline**:
  - **Haldi Ceremony**: Thursday, 03 Dec 2026 · 04:00 PM onwards
  - **Mehndi Celebration**: Friday, 04 Dec 2026 · 08:00 PM onwards
  - **Nikah & Barat**: Saturday, 05 Dec 2026 · Barat (7:00 PM), Dinner (8:00 PM), Nikah (9:00 PM), Rukhsati (11:00 PM)
- **Venue & Google Maps Integration**:
  - **Green Marriage Point**, Nabipur Dihwa, Sultanpur
  - Interactive photo gallery view (Grand Entrance Canopy & Celebration Lawn)
  - Direct Google Maps directions and live embed
- **Audio Ambience**: Romantic royal music player with floating play/pause controls.
- **Responsive & Mobile-First**: Styled using Tailwind CSS and Framer Motion.

## ✦ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4, Google Fonts (Alex Brush, Amiri, Cinzel, Cormorant Garamond, Great Vibes)
- **Animations**: GSAP, Framer Motion, Canvas Confetti
- **Icons**: Lucide React

## ✦ Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
